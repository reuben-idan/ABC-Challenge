## 📖 Overview

The **ABC Challenge** is designed to provide users with an engaging and interactive experience for learning the basics of web development.  
The project is:

- **User-friendly**
- **Intuitive**
- **Scalable**

Its core goal is to help users **practice and improve their front-end coding skills**.

---

## 🚀 Features

- **Interactive Challenges** – Explore and complete various development tasks.  
- **Modern UI/UX** – Clean and responsive design for all devices.  
- **Customizable** – Easily adaptable for different challenge types or educational purposes.  
- **Lightweight** – Built purely with HTML, CSS, and JavaScript for simplicity and speed.

**Primary Languages:**

- **HTML (94.2%)** – Structures the layout and content.

## 🧰 Installation

To get started locally:

1. **Clone the repository**  
   ```bash
   git clone https://github.com/reuben-idan/ABC-Challenge.git
   ```

2. **Navigate into the project directory**  
   ```bash
   cd ABC-Challenge
   ```

3. **Open the project in your browser**  
   - Double-click `index.html`, or  
   - Use a live server extension in your code editor.

## 📌 Usage

### Explore Challenges
